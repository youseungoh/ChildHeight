# Child Height Prediction 🦒

부모·조부모의 키와 아이의 생활습관을 입력하면 **아이의 예상 키**와 **성장 잠재력**을 계산해 주는 웹앱입니다.
순수 **HTML / CSS / JavaScript** 단일 파일(`index.html`)로 만들어졌으며, 외부 라이브러리·CDN 없이 브라우저에서 바로 동작합니다.

## ✨ 주요 기능

- **유전 예상 키 계산** — 부모 키 공식(Tanner mid-parental height)에 친가·외가 조부모 키를 반영해 정밀도 보정
- **성장환경 점수** — 수면·영양·운동·스트레스 4개 항목 설문으로 0~100점 산출, 예상 키에 소폭 가감
- **성장도표 백분위** — 질병관리청 소아·청소년 성장도표(근사치) 기반 현재 키 백분위 표시
- **맞춤 성장 팁** — 부족한 항목 우선으로 학술 근거 기반 관리 팁 제공
- **깔끔한 UI** — 산뜻한 옐로우 톤, Lucide 인라인 아이콘, 단계별 입력 흐름

## 🧮 계산 방식

**1. 유전 기본 예측 (mid-parental height)**

```
남아: (아빠 키 + 엄마 키 + 13) ÷ 2
여아: (아빠 키 + 엄마 키 − 13) ÷ 2
```

- 예상 범위는 ± 5cm로 표시합니다.

**2. 가문 키 보정** — 친가·외가에서 키가 큰 조부모 각 1명의 키를 반영해 중심값을 소폭 조정합니다.

**3. 성장환경 보정** — 성장환경 점수(수면·영양·운동·스트레스)에 따라 예상 키를 ±3cm 이내에서 가감합니다. (사춘기가 이미 시작된 경우 보정 폭 축소)

## 📊 학술적 배경

- 키는 팔다리 뼈 끝의 **성장판(골단연골)**이 열려 있는 동안, **성장호르몬(GH)**과 **IGF-1**의 작용으로 연골이 새 뼈로 바뀌며 자랍니다.
- 최종 키는 유전이 약 60~80%를 설명하지만, **수면·영양·운동·스트레스** 등 후천적 요인의 영향도 큽니다.
- 소아 비만은 사춘기를 앞당겨 성장판을 일찍 닫히게 해 최종 키를 낮출 수 있습니다.

## 🚀 사용 방법

**로컬에서 열기**

```
index.html 파일을 브라우저로 열기만 하면 됩니다. (서버 불필요)
```

**GitHub Pages로 배포**

1. 저장소에 `index.html`을 푸시
2. **Settings → Pages** 에서 브랜치를 선택해 Pages 활성화
3. `https://<사용자명>.github.io/<저장소명>/` 으로 접속

## 🛠️ 기술 스택

- HTML5 / CSS3 / Vanilla JavaScript (단일 파일)
- Lucide 아이콘 (인라인 SVG)
- 외부 의존성 없음 · 오프라인 동작 · 모든 계산은 브라우저 내에서 처리(서버 저장 없음)

## ⚠️ 면책 조항

본 예측은 유전 공식과 생활습관 설문을 바탕으로 한 **통계적 참고값**이며, 의학적 진단이 아닙니다.
생활습관 요소는 키를 정확히 수치화할 수 없어 '경향'으로만 반영됩니다.
정확한 진단은 성장클리닉의 골연령 검사를 권장합니다.
